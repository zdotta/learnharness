# 简体中文语言包（仓库镜像）

本目录是 `zdotta/learnharness-zh-plugin` 的源码镜像，随 `feat/zh-cn-language-pack` 分支提交，
用于在 LearnHarness 主仓中审阅「基于上游 v0.7.0 的插件改动」。

- 独立仓库（权威源）：https://github.com/zdotta/learnharness-zh-plugin
- 基线：LearnHarness v0.7.0 (`0292b85b`)
- 构建：`npm ci && npm run build`（依赖由 `npm run plugins:setup` 统一安装）

> 这是社区插件，不属于核心插件目录清单（`core-plugins.json` 未收录），也不参与 `plugins:build-core`。
